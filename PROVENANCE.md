# Asset provenance

- Robot ensemble: original generated RedMan concept artwork, reused unchanged.
- Music: original procedural synthesis in create-score.py; no sampled recordings or borrowed melodies.
- Typography: Noto Sans Regular/Bold and a Noto Sans CJK SC glyph subset, SIL Open Font License. See included notices. No OpenAI Sans files are included.
- GSAP 3.14.2: unmodified official distribution; license URL and copyright preserved.
- Hyperframes 0.8.171: pinned official npm dependency, not bundled.
- Poster geometry and interface: native HTML/CSS/SVG animation.

This standalone project does not include RedMan business source code, credentials, private project reports, or live customer data.
